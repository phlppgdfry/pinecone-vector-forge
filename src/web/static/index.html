Hierarchical Document Ingestion Pipeline

Documents submitted here are automatically segmented into semantic overlapping chunks, transformed into 1536-d dense embeddings + BM25 sparse vectors, and upserted directly into the active Pinecone namespace.

Core Production Architecture Patterns

1. Hybrid Convex Search (α-Weighting)

Dense embeddings capture semantic intent while sparse vectors (BM25/SPLADE) catch exact product codes, acronyms, and rare entity IDs. The convex formula score = α × dense + (1 - α) × sparse ensures balanced retrieval.

hits = index.query( vector=[v * alpha for v in dense_embedding], sparse_vector={"indices": s["indices"], "values": [v * (1 - alpha) for v in s["values"]]}, top_k=10, namespace="production" )

2. Hardware-Isolated Multi-Tenant Namespaces

Pinecone namespaces enable strict isolation for B2B SaaS tenants without incurring the idle cost of dedicated vector indexes.

# Query strictly fenced to tenant boundary index.query(vector=query_vector, namespace=f"tenant_{tenant_id}", filter={"tenant_id": tenant_id})

3. Hierarchical Parent-Document Context Hydration

Index compact 300-token chunks for pinpoint vector search accuracy, and store parent document pointers in metadata so LLM generators receive complete contextual passages without hallucination.

Official Pinecone CLI (pc) Workflow Cheat Sheet

The official Pinecone CLI (pc) is installed on your system. Use these recipes for day-to-day operations and CI/CD vector database management:

1. Authenticate with Pinecone

# Launch browser-based SSO login pc login # Check active session status pc auth status

2. Serverless Index Operations

# List all active indexes pc index list # Create a Serverless index in AWS us-east-1 pc index create --name vector-forge-knowledge --dimension 1536 --metric cosine --spec-cloud aws --spec-region us-east-1 # Inspect index statistics & vector count pc index describe --name vector-forge-knowledge

3. Namespace & Vector Management

# List namespaces in an index pc index namespace list --index vector-forge-knowledge # Perform vector search from terminal pc index record search --index vector-forge-knowledge --namespace default --top-k 5
